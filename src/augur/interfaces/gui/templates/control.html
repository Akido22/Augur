Kill switch

KILLED, режим ANALYSIS_ONLY, отмена всех ордеров, при flatten — закрытие позиций. Кода не требует. Снять можно только в CLI: augur cb reset --confirm (с одноразовым кодом).

Команды CLI

  
В GUI 0.9.0 только мониторинг и kill switch. Остальное — в CLI, с кодом или --confirm:

  
augur mode show
augur mode set <MODE> --confirm         # повышение на шаг с кодом, понижение сразу
augur orders approve <id> --confirm      # первый ордер MICRO_LIVE
augur cb status | cb reset --confirm
augur news lift <id> --confirm
augur signals explain <id>               # цепочка решения в терминале
augur audit verify-chain
